# silinex-wire-mcp

Thin stdio proxy for the public Silicon News Wire MCP.

```bash
SILINEX_WIRE_URL=https://silinex.xyz/mcp/wire npx -y silinex-wire-mcp
```

`SILINEX_WIRE_URL` defaults to `https://silinex.xyz/mcp/wire`. No token is required.

This package is **not published** yet. Build with `npm run build` after a local `npm install` in this directory.

Do not confuse this with the token-gated hub MCP at `/mcp`.
